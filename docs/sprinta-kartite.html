1. Sprinta mērķis

Lietotājs var atzīmēt bezmaksas izmēģinājuma periodu un saņem brīdinājumu par to un par gaidāmo maksājumu arī tad, kad lietotne nav atvērta. Pamatojums: pieteikumā pirmā nosauktā problēma ir aizmirsti izmēģinājuma periodi, bet pašreizējā versijā izmēģinājumu nevar atzīmēt un paziņojumi pazūd, kad cilne ir aizvērta.

2. Backlog ar akcepta kritērijiem un novērtējumu

Nr.Vienība un akcepta kritērijihStatuss pārskatā
SP1-1 Paziņojumi strādā, kad lietotne ir aizvērta. AK: manifest.json un instalējama ikona; service worker parāda paziņojumu ar aizvērtu cilni; bez atbalsta — nav kļūdu konsolē. 3
SP1-2 Bezmaksas izmēģinājuma perioda atzīme. AK: formā slēdzis “Bezmaksas izmēģinājums” + beigu datums; kartītē “Izmēģinājums līdz DD.MM.”; summa neieskaitās “Kopā mēnesī”, kamēr periods nav beidzies. 2
SP1-3 Brīdinājums pirms izmēģinājuma beigām. AK: paziņojums tik dienas iepriekš, cik norādīts iestatījumos; tekstā nosaukums, datums un summa; no paziņojuma atveras abonementa detaļas. 1,5
SP1-4 Paroles netiek glabātas atklātā tekstā. AK: SHA-256 ar nejaušu sāli (Web Crypto); localStorage nav atklāta teksta paroles; pieteikšanās ar pareizu/nepareizu paroli strādā korekti. 1,5
SP1-5 Vienībtesti datumiem un .csv importam. AK: node:test, palaižami ar npm test; segts 31.01.→28.02., mēneša kopsumma ar gada abonementu, “;” un “,” atdalītāji; visi testi iziet. 2
SP1-6 CI pārbauda arī testus. AK: GitHub Actions izpilda npm test papildus npm run build; PR ar krītošu testu ir sarkans; README ir CI nozīmīte. 1
SP1-7 Kopsumma kalendārā. AK: izvēlētajai dienai “Kopā šajā dienā: X.XX €”; pie mēneša nosaukuma redzama mēneša maksājumu kopsumma. 1
KopāPieejamais laiks 12 h. Ja apjoms nesakrīt, vienības tiek izmestas šādā secībā: SP1-7, SP1-6.12

4. Pabeigtības definīcija

  • Visi akcepta kritēriji izpildīti un pārbaudīti lietotnē
  • Kods apvienots caur pull request, nevis tieši main
  • Vismaz viena komandas biedra apskats ar komentāriem
  • CI zaļš: npm ci un npm run build bez kļūdām
  • Nav noslēpumu un .env failu; .gitignore aktuāls
  • Pārbaudīts 375 px platumā gaišajā un tumšajā režīmā
  • Pārlūka konsolē nav kļūdu
  • Nepabeigta vienība pāriet uz nākamo sprintu, nevis tiek skaitīta “gandrīz gatava”
